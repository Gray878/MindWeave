2.2.3Ne04J 介绍
Neo4J 是一种开源的，基于图形结构的 NoSQL 数据库[39]，专门为了存储和管理拥有复杂关系的数据而设计，它以图结构存储数据，将实体抽象为节点，实体间关系抽象为边，并提供高效的图查询语言，能够很好地解决复杂关系查询问题。
与 MySQL 等关系型数据库不同，Neo4J 中没有表格、数据行等概念，它是以节点(Nodes)、关系(Relationships)为基本单位来存储各种结构化信息。节点是Neo4J 中数据的基本单位，一个节点代表一个实体。关系是连接节点的边，表示实体间的语义关系，关系是有方向的，由一个实体指向另一个实体。节点和关系中还拥有标签(Labels)和属性(Properties)，标签提供分类信息，属性存储各种具体信息，用户可以使用查询语言Cypher来查询数据库中包含的各种信息。Neo4J还支持事务并且提供多种编程语言的驱动(如Python、Java等)，因此本文采用Neo4J来存储和操作知识图谱。
2.3RAG 相关理论
大语言模型拥有强大的语义理解能力和文本生成能力，知识图谱拥有存储和管理复杂结构化知识的能力，但是想要将二者有机地结合起来应用在垂直领域问答系统中，还需要一套科学的设计理念。检索增强生成（Retrieval-AugmentedGeneration,RAG)作为一种结合了信息检索技术与语言生成模型的人工智能技术，为本文研究的垂直领域问答系统设计提供了思路。

RAG是一种提升大语言模型性能的技术方法。其核心思想是通过整合外部可靠知识库的信息来提升模型的输出质量。当大语言模型接收到查询时，它不仅依赖于自身的预训练知识，还会主动从指定的知识源检索相关信息。这种方法确保了生成的输出能够参考大量上下文丰富的数据，并得到最新、最相关可用信息的支持。标准的 RAG系统主要包含三个关键组件：检索器组件（RetrieverComponent）、生成器(Generator)、知识库(Knowledge Base)。
检索器组件是 RAG 的核心模块，负责从知识库中检索与用户查询相关的内容，通常检索器组件会先使用text2vec、m3e-base等嵌入模型将用户查询和知识库中的文本转化为向量，再通过计算余弦相似度或其他距离度量来找到与用户查询相似度高的文本段落。生成器使用检索到的相关内容和用户的提问生成最终的回答，通常使用大语言模型和提示工程完成，因为大语言模型不仅能够利用提示中检索到的上下文与用户查询等信息，生成自然语言答案，还能利用自身预训练获得的能力补全生成内容，提高回答的准确性和连贯性。知识库是RAG框架中的数据来源，提供用于检索的背景知识，通常由用户上传，经过处理后存储在向量数据库或其他数据库中。

3知识库构建
1.数据预处理
多源数据分类并导入向量数据库、关系数据库。知识库原数据的导入分为四个阶段。
1)导入数据源
主要数据源包括中波发射台相关行业规范、各种标准文件、设备说明书、运维手册、故障案例、技术文献数据、后期运行及时更
新文档、中波发射台智慧监管系统数据库中的数据、常见问题与答案(FAQ)等。
2)原始数据处理
(1)格式转换：PDF/Word→Markdown.
(2)文本清洗：去噪、HTML标签、脚注、页眉页脚，去除多余的空格、标点符号，统一日期格式等，形成标准化格式。
(3)文本分割：根据长文本的内容使用不同的分割方法，如基于文档结构分块、固定大小分块（256字符，滑动窗口512字符，
重叠率15%，主要保证检索效率）和语义分块，将长文本切分为语义完整的段落、片段或块，每个片段要保证语义完整性。

3)向量化存储
由于机器学习及深度学习算法不具备处理非数值数据的能力，仅能应对数值数据，因此必须采用合适的模型来完成文本到数值向量的转换。使用嵌入模型(Qwen3-Embedding-8B)将文本(如单词、短语、句子或段落)转换为向量数据；数值数据，直接作为数值向量；日期数据转换为数值或独热编码；分类数据(如性别、国家、类别等)通常需要通过独热编码。
4)数据索引
将预处理后的数据构建成索引，以实现快速检索。所采用的索引技术包括向量索引与倒排索引：具体通过Milvus的IVF_SQ8索引(nlist=1024)构建向量索引l，借助Elasticsearch的IK分词+BM25评分机制构建倒排索引l.
4知识检索
4.1提问处理
在准备训练数据时，需要对用户提出的问题进行一系列处理，以确保数据的质量和模型的性能。
4.1.1文本清洗
对文本进行输入清洗，主要采取去除无关符号、去除停用词、全角转半角、多余空格清除、数字整形、广电行业专用词替换等方法，确保问题的准确性和专业性。例如，将10,000变为纯数字10000；将“机器”替换为“发射机”，将“设备”替换为“发射设备等。

4.1.2意图识别
基于规则的关键词匹配。从文本中提取出预定义的关键词(如发射机设备的工作模块名称、专业术语)和模式（模块功能描述）。通过关键词和术语的精确匹配，如故障诊断方面从故障现象和特征中检索诊断故障原因。例如，当发射机遇到故障时，用户可以通过描述故障现象(如“播出中断”“功率下降”“驻波比”等关键词)来获取技术支持；通过轻量级BERT模型进行意图分类，以提高处理速度和准确性，主要用于FAQ.
4.2混合检素
混合检索是一种综合性的检索方式，主要包含两大类检索方法：一类是向量检索，另一类是将关键词匹配与向量检索相结合的混合检索，以期获得比单一方法更好的搜索结果的技术。向量检索通过计算文本向量的相似度来进行信息检索，而关键词匹配则侧重于根据预设的关键词来筛选相关内容。两种方法的有机结合，旨在显著提升检索的准确性和效率，确保用户能够更快地找到所需信息，同时减少无关结果的干扰，从而优化整体的检索体验。检索过程如图3所示。

1.3检索增强生成(RAG)技术
检索增强生成是一种将信息检索与文本生成相结合的技术框架，其核心思想是在用户将提示词发送至大语言模型前，先从外部识库中检索与用户问题相关的文本信息，并将检索结果作为上下文输入至大语言模型中，从而使大语言模型获取问题相关内容并生成更加准确和可靠的回答。
RAG典型流程包括文档文本向量化、语义检索以及结果融合生成等步骤。通过将特定领域知识以向量形式存储在向量数据库中，RAG系统能够在用户提问时与向量数据库中的向量进行向量相似度匹配，并获取与问题最相关的知识片段。相比于仅依赖通用知识的大语言模型，RAG技术能够有效缓解模型知识不足和幻觉问题，在特定领域知识问答任务中具有较好的应用效果。

2.2通过多路召回扩大召回覆盖面
前期平台仅依赖向量相似度进行单路召回，缺乏关键词和内容标签等互补信号。为提高召回覆盖度，将单一召回链路扩充为“内容标签匹配召回+结构化关键词召回+向量召回”的三路并行召回机制。召回路径一为内容标签匹配召回，使用用户查询中提取的标签匹配文档标签库，先匹配到文档标签，再从具有匹配标签的文档集合中召回相关文档切片；路径二为结构化关键词召回，基于从用户查询中提取的检索词，精准检索文档元数据中的标题、文号等结构化字段，获取高相关切片；路径三为向量召回，将完整问题向量化后在知识向量库中检索相似问答案例切片，补充语义相似但关键词不一致的内容。三个路径结果在召回规模、相似度阈值与权重上进行差异化配置，经过去重、权重融合与重排，形成最终候选证据集，并在生成阶段强制引用来源以保证可追溯性。

多路召回能够兼顾精确匹配与语义泛化。标签与关键词路径提供高精度过滤，向量路径提供语义扩展与同义召回，三路融合可显著减少单一路径的盲区。在业务领域知识密集且术语差异显著的场景中，多路召回能够提升长尾问题的覆盖率，同时避免仅靠向量相似度带来的语义漂移。通过对不同路径赋权与重排，系统可在召回覆盖与精度之间取得平衡，提升复杂问题与跨条线问题的命中率，降低因召回不足导致的“无相关信息”反馈，并为结果控制提供更稳定的证据基础。多路召回还能支撑不同问题类型的路由策略，例如事实类优先关键词召回、流程类优先标签召回、解释类优先向量召回。长期来看，多路召回为检索系统提供了可监控、可调参的处理抓手。

1.2知识图谱相关研究

知识图谱是一种以实体、关系及其属性为基本单元的知识表示与组织方式。自2012年提出以来，逐渐成为人工智能领域的重要研究方向[24]。其通过图结构组织知识，能够较好呈现知识之间的语义关联，并支持复杂推理分析，因此在情报分析、风险预警和智能决策等场景中具有较强应用价值[25]。从应用范畴来看，知识图谱可分为通用领域和垂直领域两大类型。通用知识图谱如Wikidata、YAGO2、DBpedia和Freebase[26]等，具有覆盖面广、知识粒度粗等特点；相较之下，垂直领域知识图谱更强调场景适配与知识精细表达[27]，通常通过领域本体设计、概念约束和语义细化实现专业知识组织，已在医疗[28]、教育[29]、网络安全预警[30]和事故风险评估[31]等领域得到广泛应用。这一发展趋势表明，围绕特定任务构建领域知识图谱，已成为提升知识服务适配性与可用性的重要路径。在技术层面，知识图谱相关方法经历了由规则方法、特征工程向深度学习[32]和大模型驱动[33]的方向演进。在实体识别[34]、关系抽取、实体对齐和多源融合[35]等方面，现有研究已积累较为成熟的方法基础。特别是大模型的发展，进一步提升了复杂语境下的语义理解和知识抽取能力，也为知识图谱构建提供了新的技术条件[36]。

1.3多模态大模型在知识抽取中的应用研究
多模态大模型在知识抽取领域展现出较强的应用潜力。相较于传统单一模态方法，其能够协同处理文本、图像、音频等多模态信息，从而更完整地表征复杂场景中的语义关系[37][38]，为弱信号知识抽取任务带来范式革新。在技术层面，现有研究主要聚焦跨模态对齐与融合、指令微调与提示工程及多源异构数据抽取等方面。多模态大模型能够通过对比学习、交叉注意力等机制实现不同模态信息的语义对齐，在一定程度上缓解了单一模态条件下的语义稀疏与噪声干扰问题[39][40]。同时，借助指令微调和提示工程，模型能够根据任务需求执行特定的知识抽取指令，提高多模态数据知识抽取过程的准确性和可控性[41]。面对多源异构数据场景，多模态大模型还可通过检索与生成迭代领域多模态知识图谱，从而做出最优应对决策[42]。在应用层面，现有研究已在多个垂直领域展开探索。例如，在工业领域，通过集成大模型与多模态融合技术实现数控机床故障诊断知识图谱的构建[43]；在信息系统领域，通过设计双阈值时间采样算法，结合提示工程驱动多模态大模型，实现视觉信息的精确提取[44]；在情报领域，通过多模态大模型构建社交媒体多模态情感分析模型，解决了特征表示不完全及多模态信息语义互斥的复杂性问题[45]。上述研究为多模态大模型在弱信号的知识抽取、融合及推理应用提供了重要理论基础与技术启示。
