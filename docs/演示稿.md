# PandaWiki 智能知识库系统 - 毕设演示稿

## 一、项目概述

PandaWiki 是一款基于 AI 大模型驱动的开源知识库搭建系统，旨在帮助企业和团队快速构建智能化的产品文档、技术文档、FAQ 和博客系统。系统借助大模型的力量，提供 AI 创作、AI 问答、AI 搜索等智能化能力。

---

## 二、系统演示流程

### 1. 管理员登录

**演示步骤：**
- 打开浏览器，访问管理后台地址：`https://<服务器IP>:2443`
- 输入管理员账号：`admin`
- 输入管理员密码（首次安装时系统自动生成）
- 点击"登录"按钮进入控制台

**功能说明：**
系统采用安全的身份认证机制，支持 JWT Token 认证，确保管理后台的访问安全。

### 2. AI 模型配置（首次登录必选）

**演示步骤：**

#### 2.1 一键自动配置（推荐）
- 首次登录时，系统会自动弹出"AI 模型配置"引导页
- 选择"一键自动配置"选项
- 系统会自动配置以下模型：
  - **对话模型**：用于 AI 问答和智能对话
  - **嵌入模型**：用于文档向量化和语义检索
  - **重排序模型**：用于搜索结果优化排序
- 点击"完成配置"

#### 2.2 手动自定义配置（高级选项）
- 选择"手动自定义配置"
- 配置对话模型：
  - 选择模型提供商（OpenAI、百智云、通义千问等）
  - 输入 API Key
  - 选择具体模型（如 GPT-4、Claude-3.5 等）
- 配置嵌入模型：
  - 选择嵌入模型提供商
  - 输入相应的 API Key
  - 选择向量维度
- 配置重排序模型（可选）
- 点击"测试连接"验证配置
- 保存配置

**功能说明：**
- 支持多种主流 AI 模型提供商
- 灵活的模型配置，可根据业务需求选择不同模型
- 推荐使用百智云模型广场，注册即送 5 元额度

### 3. 创建知识库

**演示步骤：**
- 点击左侧导航栏的"知识库管理"
- 点击右上角"创建知识库"按钮
- 填写知识库基本信息：
  - **知识库名称**：例如"产品技术文档"
  - **知识库描述**：简要说明知识库用途
  - **知识库图标**：上传或选择 Emoji 图标
- 配置访问设置：
  - **访问域名/端口**：设置前端知识库访问地址
  - **SSL 端口**：配置 HTTPS 访问端口（如 443）
  - **HTTP 端口**：配置 HTTP 访问端口（如 80、8080）
- 点击"保存"完成创建

**功能说明：**
- 支持创建多个独立的知识库
- 每个知识库拥有独立的访问地址和配置
- 灵活的端口配置，支持 HTTP 和 HTTPS 访问

### 4. 文档导入功能

系统提供强大的多源文档导入能力，支持批量导入和多模态内容。

#### 4.1 通过离线文件导入

**演示步骤：**
- 进入"文档管理"页面
- 选择目标文件夹（或在根目录）
- 点击右键菜单 → "导入文档" → "通过离线文件导入"
- 支持的文件格式：
  - **文档类**：PDF、Word（.doc/.docx）、Markdown（.md）、TXT
  - **表格类**：Excel（.xls/.xlsx）、CSV
  - **演示类**：PowerPoint（.ppt/.pptx）
  - **图片类**：PNG、JPG、JPEG、GIF（支持 OCR 识别）
  - **其他**：HTML、Epub、JSON
- 选择文件（支持批量选择）
- 点击"开始上传"

**处理流程：**
1. **文件上传**：文件上传至 MinIO 对象存储
2. **格式解析**：系统自动识别文件格式并进行内容提取
3. **文本清洗**：去除无效字符、格式化文本
4. **向量化处理**：使用嵌入模型将文本转换为向量
5. **索引构建**：在 Qdrant 向量数据库中建立索引
6. **知识图谱生成**：提取实体和关系，存储至 Neo4j 图数据库
7. **学习完成**：文档状态更新为"已学习"，可用于 AI 问答

#### 4.2 通过 URL 导入

**演示步骤：**
- 点击"导入文档" → "通过 URL 导入"
- 输入网页 URL（支持批量输入，每行一个）
- 配置爬取选项：
  - 是否包含子页面
  - 爬取深度限制
  - CSS 选择器（可选，用于精确提取内容）
- 点击"开始导入"

**功能说明：**
- 自动爬取网页内容并提取正文
- 支持 JavaScript 渲染的动态页面
- 智能去除导航栏、广告等无关内容

#### 4.3 通过 RSS 订阅导入

**演示步骤：**
- 点击"导入文档" → "通过 RSS 导入"
- 输入 RSS 订阅地址
- 设置更新频率（每日/每周/每月）
- 点击"订阅"

**功能说明：**
- 自动定期拉取 RSS 更新
- 适合博客、新闻等持续更新的内容源

#### 4.4 通过 Sitemap 导入

**演示步骤：**
- 点击"导入文档" → "通过 Sitemap 导入"
- 输入 Sitemap XML 地址
- 选择要导入的页面（支持批量选择）
- 点击"开始导入"

**功能说明：**
- 批量导入整站内容
- 自动解析 Sitemap 结构
- 适合文档站点的快速迁移

#### 4.5 通过第三方平台导入

系统支持从多个主流平台直接导入：

**Notion 导入：**
- 输入 Notion Integration Token
- 选择要导入的 Page 或 Database
- 保持原有层级结构

**语雀导入：**
- 输入语雀 Token
- 选择知识库
- 自动同步文档结构

**飞书文档导入：**
- 授权飞书应用
- 选择文档或文件夹
- 批量导入

**其他支持平台：**
- 钉钉文档
- Confluence
- Wiki.js
- 思源笔记
- MinDoc

#### 4.6 批量导入状态监控

**演示步骤：**
- 导入任务提交后，在"文档管理"页面可以看到文档状态
- 文档状态标识：
  - 🟡 **待学习**：文件已上传，等待处理
  - 🔵 **学习中**：正在进行向量化和知识提取
  - 🟢 **已完成**：学习完成，可用于 AI 问答
  - 🔴 **学习失败**：处理出错，可点击"重新学习"

**实时进度：**
- 页面顶部显示："X 个文档未学习，去学习"
- 点击可批量重新学习失败的文档

### 6. 知识图谱可视化

系统自动构建文档间的知识图谱，展示实体和关系。

#### 6.1 2D 可视化

**演示步骤：**
- 点击左侧导航栏"知识图谱"
- 默认显示 3D 视图，点击右上角切换到"2D"
- 图谱展示：
  - **节点类型**：
    - 🟦 文档节点（蓝色）
    - 🟧 实体节点（橙色）
    - 🟩 概念节点（绿色）
  - **连线**：表示节点间的关联关系
  - 连线粗细表示关联强度

**交互操作：**
- **缩放**：鼠标滚轮缩放视图
- **拖拽**：拖动画布查看不同区域
- **点击节点**：高亮显示相关联的节点
- **双击节点**：打开文档详情弹窗
- **搜索**：顶部搜索框快速定位节点

#### 6.2 3D 可视化

**演示步骤：**
- 点击右上角切换到"3D"视图
- 3D 图谱特性：
  - 立体空间展示，更直观的层级关系
  - 支持旋转、缩放、平移
  - 节点大小表示重要程度
  - 颜色区分不同类型

**交互操作：**
- **旋转**：鼠标左键拖动旋转视角
- **缩放**：鼠标滚轮缩放
- **平移**：鼠标右键拖动平移
- **双击节点**：弹出文档详情窗口，显示：
  - 文档标题和摘要
  - 关联的实体列表
  - 相关文档推荐
  - 快速跳转按钮

#### 6.3 图谱统计信息

**演示步骤：**
- 页面顶部显示图谱统计：
  - 📊 **节点数**：总节点数量
  - 🔗 **关系数**：总关系数量
  - 📄 **文档数**：文档节点数量
  - 🏷️ **实体数**：实体节点数量
  - 📈 **平均连接数**：每个节点的平均关联数

**功能说明：**
- 实时统计知识图谱规模
- 帮助评估知识库的完整性和关联度

#### 6.4 图谱同步与维护

**演示步骤：**
- 点击"重放死信"按钮
- 系统会重新处理失败的图谱同步任务
- 显示处理结果："已处理 X 条，成功 Y 条，失败 Z 条"

**功能说明：**
- 自动同步文档更新到知识图谱
- 支持手动触发重新构建
- 确保图谱数据的准确性

### 1. 前端技术栈

- **前台网站**：Next.js + React + TypeScript
- **状态管理**：Redux Toolkit

- **API 服务**：Go + Gin 框架
- **消息队列**：NATS
- **任务调度**：Go Routine + Channel

### 3. 数据存储
- **关系数据库**：PostgreSQL（存储结构化数据）

- **图数据库**：Neo4j（存储知识图谱）
- **对象存储**：MinIO（存储文件和图片）
- **缓存**：Redis（缓存热点数据）

### 4. AI 能力
- **大语言模型**：支持 OpenAI、Claude、通义千问等
- **嵌入模型**：支持多种向量化模型
- **RAG 技术**：检索增强生成，提高回答准确性
- **知识图谱**：自动提取实体和关系

### 5. 部署方案
- **容器化**：Docker + Docker Compose
- **反向代理**：Nginx + Caddy
- **HTTPS 支持**：自动生成 SSL 证书
- **水平扩展**：支持多实例部署
