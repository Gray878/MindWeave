## 详细功能说明

### 专业版独占功能 (Professional+)

#### 1. 管理员分权控制
- 支持多个管理员账号 (最多 20 个)
- 可以为不同管理员分配不同权限
- 位置: 设置 → 知识库设置 → 用户管理

#### 2. 高级 SEO 配置
- 自定义 meta 标签
- 自定义 robots.txt
- 站点地图优化

#### 3. 多语言支持
- 支持多语言界面
- 自定义语言包

#### 4. 自定义版权信息
- 自定义页脚版权文字
- 自定义品牌信息

#### 5. 高级流量分析
- 支持查看近 7 天的访问数据
- 更详细的用户行为分析

#### 6. 自定义 AI 提示词
- 自定义 AI 问答的系统提示词
- 优化 AI 回答质量

---

### 商业版独占功能 (Business+)

#### 1. 访客权限控制
- 细粒度的访客访问控制
- 支持白名单/黑名单
- 位置: 设置 → 知识库设置 → 访问控制

#### 2. 用户组管理
- 创建和管理用户组
- 为用户组分配权限
- 位置: 设置 → 用户组

#### 3. SSO 单点登录
- 支持 OAuth 2.0
- 支持 LDAP
- 支持 CAS
- 支持企业微信登录
- 最多支持 2000 个 SSO 用户
- 位置: 设置 → 登录认证

#### 4. 页面水印
- 为页面添加水印
- 防止内容泄露
- 位置: 设置 → 安全设置

#### 5. 内容不可复制
- 禁止用户复制页面内容
- 保护知识产权
- 位置: 设置 → 安全设置

#### 6. 敏感内容过滤
- 过滤 AI 问答中的敏感关键词
- 自定义屏蔽词列表
- 位置: 设置 → 安全设置

#### 7. 文档历史版本管理
- 查看文档的历史版本
- 恢复到指定版本
- 版本对比功能

#### 8. API 调用
- 提供 RESTful API
- 支持第三方系统集成
- API Token 管理
- 位置: 设置 → API Token

#### 9. MCP 协议支持
- 支持 Model Context Protocol
- 与 AI 工具深度集成
- 位置: 设置 → MCP 配置

#### 10. 高级流量分析
- 支持查看近 30 天、90 天的访问数据
- 地域分布分析
- 热力图分析
- 位置: 统计页面

---

### 企业版独占功能 (Enterprise)

#### 1. 无限配额
- 无限 Wiki 站点数量
- 无限文档数量
- 无限管理员数量
- 无限 SSO 用户数量

#### 2. 项目源码
- 获得完整的项目源代码
- 可以进行二次开发

#### 3. 企业级支持
- 专属技术支持
- 定制化开发服务
- SLA 保障

## 代码中的版本控制位置

### 1. 统计页面时间范围限制
**文件**: `PandaWiki/web/admin/src/pages/stat/Statistic/index.tsx`
- 开源版: 仅支持近 24 小时
- 专业版: 支持近 7 天
- 商业版/企业版: 支持近 30 天、90 天

### 2. 用户组管理
**文件**: `PandaWiki/web/admin/src/pages/setting/component/UserGroup/index.tsx`
- 仅商业版和企业版可用

### 3. 安全设置
**文件**: `PandaWiki/web/admin/src/pages/setting/component/CardSecurity.tsx`
- 页面水印: 商业版+
- 内容不可复制: 商业版+
- 敏感内容过滤: 商业版+

### 4. API Token 管理
**文件**: `PandaWiki/web/admin/src/pages/setting/component/CardKB.tsx`
- 仅商业版和企业版可用

### 5. 登录认证
**文件**: `PandaWiki/web/admin/src/pages/setting/component/CardAuth.tsx`
- OAuth/LDAP/CAS/企业微信登录: 商业版+

### 6. MCP 配置
**文件**: `PandaWiki/web/admin/src/pages/setting/component/CardMCP.tsx`
- 仅商业版和企业版可用

### 7. 问答机器人 API
**文件**: `PandaWiki/web/admin/src/pages/setting/component/CardRobotApi.tsx`
- API Token: 商业版+

## 如何移除版本限制

如果你想在开发环境中移除这些版本限制,可以:

### 方法 1: 修改版本常量
编辑 `PandaWiki/web/admin/src/constant/version.ts`,将所有功能的权限改为开源版也支持。

### 方法 2: 修改组件权限检查
在各个组件中,找到 `permission={BUSINESS_VERSION_PERMISSION}` 或 `BUSINESS_VERSION_PERMISSION.includes(license.edition!)` 的地方,移除或注释掉这些检查。

### 方法 3: 模拟商业版许可证
修改后端返回的 license 信息,将 edition 设置为 `LicenseEditionBusiness` 或 `LicenseEditionEnterprise`。

## 建议

对于毕业设计项目,建议:

1. **保留基础功能**: 文档管理、AI 问答、基础统计
2. **移除商业限制**: 将需要的功能改为开源版可用
3. **重点开发**: 知识图谱相关的新功能
4. **简化功能**: 删除不需要的第三方集成 (飞书、钉钉、企业微信等)

这样可以专注于核心功能和毕设要求的知识图谱功能开发。
