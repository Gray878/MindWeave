# 硬件电路的设计
3.1系统功能分析以及体系结构设计
STM32F103C8T6单片机+两位白色高亮LED灯+WIFI模块ESP8266+电源
3.2.系统功能分析
在手机上发送指令：
打开LED1的开关，LED1亮；打开LED2的开关，LED2亮
打开LED1的一档亮度时，LED1出现一档亮度；
打开LED1的二档亮度时，LED1出现二档亮度；
打开LED1的三档即最高亮度时，LED1出现三档亮度；
打开LED2的一档亮度时，LED2出现一档亮度；
打开LED2的二档亮度时，LED2出现二档亮度；
打开LED2的三档即最高亮度时，LED2出现三档亮度；
打开全部打开开关时，两个LED灯都打开并且为最高亮度；
点击全部关闭开关时，两个LED灯都为关闭状态。
